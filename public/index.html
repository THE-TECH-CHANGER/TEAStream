OBS Studio Configuration (1-Minute Setup)

  1. Ensure your Windows Gaming PC and MacBook are on the same Wi-Fi / LAN network.
  2. Open OBS Studio on your Windows PC.
  3. Go to Settings > Stream.
  4. Set Service to Custom...
  5. Set Server to: rtmp://192.168.1.8:1935/live
  6. Set Stream Key to: ...
  7. Under Settings > Output, keep standard NVENC at 8,000 kbps.
  8. Click Start Streaming in OBS on Windows!
